Prueba 4: Token incorrecto

Explica qué debería pasar si el token no coincide con el esperado.

Respuesta:
El sistema debería bloquear el acceso a la ruta protegida y responder con un mensaje indicando que el token es inválido o que no existe autorización.

5. ¿Qué hace el middleware simple?

Respuesta:
El middleware simple revisa si existe un token pedagógico válido antes de permitir el acceso a una ruta protegida del proyecto.

6. ¿Por qué este middleware no debe confundirse con seguridad real?

Respuesta:
Porque es únicamente una práctica educativa y no utiliza cifrado, autenticación avanzada, manejo seguro de sesiones ni protección real de usuarios.

7. ¿Qué aprendiste sobre rutas públicas y rutas protegidas?

Respuesta:
Aprendí que las rutas públicas pueden consultarse libremente, mientras que las rutas protegidas requieren validaciones previas como login o token para permitir el acceso.
